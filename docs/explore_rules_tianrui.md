### 一、自主探索模式交互规则（四川天瑞大屏项目）

1. **菜单常显与默认初始状态**：
   - 屏幕顶部横向常驻显示一级业务导航菜单。
   - 应用程序启动后默认处于【首页】或【矿山简介】。
2. **菜单交互机制与悬停展开**：
   - 二级菜单通常为隐藏的下拉浮层，**必须先使用 `hover` (悬停) 动作在对应一级菜单上方停留**，等待下拉的二级菜单在顶部展开后，才能去点击里面的子模块。
   - **在鼠标未悬停展开前，页面上根本不存在该二级菜单**，严禁在未展开时凭空寻找二级菜单！
3. **严禁混淆首页预览卡片与二级业务页面**：
   - 【首页】内容区可能存在同名的数据概览卡片。**它仅仅是首页的汇总组件，绝不是二级业务页面！**
   - 若探索目标是二级菜单【X】，必须通过顶部导航栏悬停对应一级菜单展开并点击进入真正的二级页面，绝对严禁在首页卡片原地打转。
4. **深度优先探索 (DFS)**：
   - 当你通过点击**下拉子菜单**进入一个全新的具体页面时，请优先深度探索该页面内的新元素（如按钮、列表、表单、图表等）。
   - 直到把当前页面的核心功能测试完毕后，再去悬停顶部其他的一级菜单寻找新模块。切勿在各个一级菜单之间频繁悬停切换，而忽略了具体页面内部的深度测试。
5. **防误触与破坏性按钮禁止点击**：
   - 请勿点击退出、关机、关闭系统等致命按钮，避免程序意外中断。
   - 若画面中出现“是否退出当前应用？”、“确定退出系统吗？”等二次确认弹窗，**绝对严禁点击【确定/OK/退出】！必须且只能点击【取消/Cancel/❌】保留在应用内**。
6. **一键隐藏与展开即刻闭环原则**：
   - 严禁随意无故点击“一键隐藏/收起”按钮。一旦点击，大屏两侧 2D 业务面板将全量隐藏。
   - 若测试了“一键隐藏”，**紧随其后的下一步必须立即点击【一键展开/一键显示】将其还原**！
   - 若任何时候截图中发现页面处于面板隐藏状态（左右无面板，仅剩 3D 地图），第一优先级任务是点击【一键展开】恢复界面，严禁在隐藏状态下寻找其他业务控件。
7. **三维/UE 像素流大屏交互规范**：
   - 页面中央展示的三维数字孪生矿山属于 **UE 像素流推流（WebRTC/Canvas 渲染）**。
   - 优先聚焦于大屏**左侧、右侧及下方的 2D 业务面板**（包括指标卡片、Echarts 折线/柱状图维度切换、表格、明细弹窗、筛选器等）。
   - 若针对 3D 视口进行测试，仅支持已标准化的 `rotate_3d`、`zoom` 或 `canvas_stress_drag`，严禁盲目点击未知的 3D 坐标。
8. **接口与数据断言规则**：
   - 严格遵守矿山大屏“三大铁律”：UI 必须忠于 API，动态必须流动，数据不能违背物理常识。
   - 对异常数字（如负人数、`NaN`/`undefined`、超现实数值）进行最高级别报警。
